# Security Policy

## Supported versions

The `main` branch is the supported version of ROCK.

## Reporting a vulnerability

Please do not open a public issue for a suspected security vulnerability.

Report security issues privately through GitHub's Security Advisories feature for this repository. Include a clear description of the issue, affected file or URL, reproduction steps when safe to provide, and the potential impact.

Please allow reasonable time for validation and remediation before public disclosure.

## Scope

This policy covers the ROCK website, its committed frontend code, GitHub Actions workflows, and repository configuration that can affect the deployed site.

The current site is a static GitHub Pages storefront. It does not process payment credentials or store customer accounts on its own backend.
