# ROCK — Power Your Everyday

ROCK storefront rebuilt from scratch with a navy-and-blue brand system, the original ROCK logo, real web fonts, and a catalog limited to products carrying an active price.

## Live
https://nashhal.github.io/ROCK/

## Source of products
Product imagery is kept under `assets/products/`. The ROCK catalog PDF remains in the repository as the source document. Product prices currently displayed by the site are the priced entries carried forward from the project's 2026 price list.

## Frontend
- Arabic RTL by default with English toggle
- Manrope + IBM Plex Sans Arabic
- Navy / blue / white visual identity
- Search, category filters and price sorting
- Client-side cart using local storage
- Responsive desktop / tablet / mobile layout
- Original ROCK logo at `assets/brand/rock-logo.svg`

## Commerce boundary
This build is a frontend storefront. Payment processing, stock synchronization, shipping, tax and order APIs are not connected yet.
